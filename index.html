MCP engineering for companies that don't want to hire for it

The Model Context Protocol is how an AI assistant reaches your systems — your ERP, your CRM, the in-house tool nobody outside the company has ever heard of. We build those connections, make them safe enough for real data, and keep them working as the protocol moves.

Most of what is written about MCP is written from the specification. What follows on this site is written from a server that runs in production, with OAuth, a real user and logs we read every day. Where a claim below is measured, the measurement is shown.

What we do

Four kinds of work

Servers for internal and legacy systems

The systems no vendor will ever ship an official MCP server for: in-house tools, regional software, the database behind a twenty-year-old process. The hard part is rarely the protocol — it is deciding which handful of actions a model should be given, and what it must never do alone.

Security and authorisation review

Published surveys of public MCP servers keep finding the same two holes: no authorisation at all, or a single static API key standing in for one. We review what you have against how hosts actually behave, and fix the parts that only look safe.

Readiness for the 2026-07-28 specification

The July release turned the protocol stateless and deprecated the old transport with a twelve-month runway. If your server holds per-session state, it is on that clock. We audit what actually depends on sessions and write the migration plan — see the note below on why the migration itself cannot be executed yet.

Interactive UI inside the chat (MCP Apps)

Not every answer should be a paragraph. A queue with approve buttons, a card, a tracker the user ticks — rendered inside the assistant, backed by your data. We have shipped these to Claude on web and on mobile and can tell you precisely where the edges are.

Notes from production

Writing

Each of these started as something that broke, surprised us, or contradicted the documentation. Numbers are ours and reproducible.

  • 2026-08-10 The MCP spec shipped one day after its SDK — and the SDK still can't speak it

    The stateless rewrite landed on 28 July with a twelve-month migration window. The TypeScript SDK that would implement it was published on 27 July and tops out at the November 2025 protocol. Nobody is migrating yet, and that is worth knowing before you plan a sprint.

  • 2026-08-10 Your tool results are being read as an attack

    We put behaviour rules in the text our tools returned, because the legitimate channel never reached the model. Then a user saw the host warn them that our connector had attempted to inject malicious instructions. The detector was right about the shape.

  • 2026-08-10 What the host doesn't deliver

    A field guide to the channels between your server and the model: which ones arrive, which silently don't, and what each costs. Four findings, each caught by a marker test rather than by reading the specification.
