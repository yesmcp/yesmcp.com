Privacy

This is a static site. It sets no cookies, runs no analytics, embeds no trackers and loads nothing from a third-party domain — the fonts are served from here, and there is no JavaScript on any page. Nothing about your visit is collected by me.

What the host sees

The site is served by Cloudflare Pages. Like any web host, Cloudflare processes the technical request data needed to deliver a page — IP address, user agent, the URL requested — and I may see aggregate traffic counts through their dashboard. I do not have, and do not build, a per-visitor profile.

If you email me

Mail to yes@yesmcp.com is forwarded to a personal mailbox and read by me. I keep the correspondence for as long as the conversation is useful, use it only to answer you, and never add anyone to a list or pass an address to a third party. Ask and I will delete the thread.

If we work together

An engagement is a different matter, and it gets its own written agreement before anything starts — including who controls the data your system holds, where it goes, and what happens to access credentials at the end. Nothing on this site creates that agreement.

Changes

If this page changes materially, the date at the top changes with it. Questions or a request to remove something: yes@yesmcp.com.
